Algorithm Logic & Theory

This solution uses Dynamic Programming (DP) to find the Longest Palindromic Substring. Instead of repeatedly checking if substrings are palindromes from scratch, it builds upon previously solved smaller subproblems using a 2D boolean table dp.

Core Steps:

  • State Definition
    Let dp[i][j] be true if the substring s[i..j] is a palindrome, and false otherwise.
  • Base Cases
    1. Every single character is a palindrome: dp[i][i] = true.
    2. A two-character string is a palindrome if both characters are identical: dp[i][i+1] = (s[i] == s[i+1]).
  • Recurrence Relation
    For strings of length greater than 2, a string s[i..j] is a palindrome ONLY if:
    a) Its boundary characters match: s[i] == s[j]
    b) The internal substring is also a palindrome: dp[i+1][j-1] == true
    Using this relation, we can solve larger lengths relying solely on smaller lengths.
Time Complexity O(N²)

Where $N$ is the length of the string. We fill a 2D array of size $N \times N$. Each cell takes $O(1)$ constant time to compute because we rely on previously computed answers instead of scanning the substring.

Space Complexity O(N²)

The algorithm requires a 2D boolean array dp[n][n] to memoize the states, which takes $O(N^2)$ space. Note: This can be optimized to $O(1)$ space using the "Expand Around Center" approach, but DP is visually excellent for understanding subproblems.
