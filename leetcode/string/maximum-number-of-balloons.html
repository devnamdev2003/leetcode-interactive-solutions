Algorithm Logic & Theory

This solution effectively uses a Frequency Array (Hash Map alternative) pattern to solve the problem. Since we only care about lowercase English letters—and more specifically, just 5 specific letters—we can bypass complex HashMaps and simply use a primitive integer array for massive performance gains.

Core Steps:

  • Step 1: Count Frequencies
    We initialize an array a of size 5. We iterate through the given string exactly once. We use a switch statement to map 'b', 'a', 'l', 'o', and 'n' to indices 0 through 4 respectively, incrementing the count for matching characters.
  • Step 2: Adjust for Duplicates
    The target word "balloon" requires one 'b', one 'a', one 'n', but two 'l's and two 'o's. To normalize our counts so we can just find the minimum, we divide the counts of 'l' (index 2) and 'o' (index 3) by 2.
  • Step 3: Find the Bottleneck (Minimum)
    The maximum number of times we can form "balloon" is entirely dependent on our most scarce resource. We iterate through our adjusted frequency array to find the minimum value, returning it as the final answer.
Time Complexity O(N)

Where $N$ is the length of the string. We iterate through the characters of the string exactly once to populate the frequency array. The subsequent operations (division and finding the minimum) operate on a fixed-size array of 5 elements, which is $O(1)$. Therefore, the total time bound is strictly linear.

Space Complexity O(1)

The auxiliary space is $O(1)$. We create an integer array of exactly size 5, regardless of how large the input string is. (Note: In Java specifically, toCharArray() creates a copy of the string taking $O(N)$ space. To be strictly $O(1)$ in Java, one would use text.charAt(i) in a standard for-loop.)
