Sliding Window Logic

This solution uses the highly efficient Sliding Window technique combined with a direct-access map (an array mapping ASCII character values to indices).

Core Concept:

  • The "Window"
    We maintain a window defined by pointers [left, right]. This window represents the longest valid substring ending at right without any duplicate characters.
  • Character Index Map
    Instead of using a HashSet and slowly removing elements one by one from the left when a duplicate is found, we store the most recent index of every character we encounter in an integer array charIndexMap.
  • The $O(1)$ Window Jump (The "Aha!" Moment)
    When expanding right, if we see a character that exists in our map and its previous index is greater than or equal to left (meaning it is currently inside our window), we don't need a loop to shrink the window. We immediately teleport left to charIndexMap[char] + 1. This skips all overlapping elements instantly!
Time Complexity O(N)

Where $N$ is the length of string $s$. Both left and right pointers traverse the string forwards. right visits each char once, and left makes direct jumps, bypassing intermediate indices. The entire string is processed in a single pass.

Space Complexity O(m)

Where $m$ is the character set size. Since we use a fixed integer array new int[128] to store ASCII values, the auxiliary space consumed is strictly bounded to $O(128) \approx O(1)$. It does not scale with the string length.
