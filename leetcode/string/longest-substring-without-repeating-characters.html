Sliding Window Logic & Theory

This algorithm uses the Sliding Window pattern heavily optimized with a direct access array (acting as a Hash Map). It efficiently finds the longest substring without repeating characters by maintaining a "window" of valid characters.

Core Mechanics:

  • The Window (left to i):
    The window boundaries are defined by two pointers: left and i (right). At any given point, the substring from s[left] to s[i] contains no repeating characters.
  • O(1) Lookup with int[128]:
    Instead of scanning the window to check for duplicates, we use an array arr of size 128 (covering all ASCII characters). arr[c] stores the most recent index where character c was seen. It is initialized to -1.
  • Handling Duplicates (The Jump):
    When expanding the right boundary (i), we check if the current character c was seen inside the current window (arr[c] >= left). If it is, the window is now invalid. We instantly fix it by moving the left pointer to arr[c] + 1. This skips over all characters up to the duplicate in a single O(1) jump.
Time Complexity O(N)

Where N is the length of the string. Both the left and i pointers only move forward. The i pointer iterates exactly N times. The array lookups take O(1) time. Thus, the overall time complexity is strictly linear.

Space Complexity O(1)

The auxiliary array arr is always of fixed size 128 (for ASCII), regardless of the input string's length. Since the memory used does not scale with N, it is technically O(1) constant space.
