Algorithm Logic & Theory

Randomized Quick Sort is a highly efficient, Divide and Conquer sorting algorithm. By picking a random pivot, it consistently avoids the worst-case time complexity that standard Quick Sort suffers when given already-sorted arrays.

Core Concept & Steps:

  • Divide & Conquer: The algorithm continuously divides the array into smaller subarrays based on a chosen element known as the pivot.
  • Randomized Pivot: Instead of always picking the first or last element, a random index is selected within the bounds [low, high]. This element is swapped to the front and used as the pivot, ensuring balanced partitions on average regardless of the initial array order.
  • Partitioning (Hoare-like variation): Two pointers, i and j, traverse the array. Pointer i looks for an element greater than the pivot, and j looks for an element smaller than or equal to the pivot. When both find such elements, they are swapped.
  • Pivot Placement: Once pointers cross, the pivot is swapped into its final, perfectly sorted position at index j. Elements to the left are smaller, elements to the right are greater.
Time Complexity O(N log N) Average

Because we pick the pivot randomly, the array is partitioned into two roughly equal halves on average. Thus, the recursion tree has a depth of $\log N$ and each level takes $O(N)$ partitioning work. Worst-case $O(N^2)$ is practically eliminated.

Space Complexity O(log N)

Quick Sort is an in-place sort, meaning it uses $O(1)$ auxiliary data structure space. However, it requires $O(\log N)$ space on average for the recursive call stack. In the worst case (highly improbable here), it could be $O(N)$.
