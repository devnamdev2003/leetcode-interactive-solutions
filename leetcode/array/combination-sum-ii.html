Algorithm Logic & Theory

This solution utilizes Backtracking to explore all potential combinations that sum up to the target. To satisfy the requirement that each number can only be used once per combination and to prevent duplicate combinations, specific pruning strategies are applied.

Core Steps & Strategies:

  • Sorting (Crucial Step):
    The array is sorted at the very beginning. This groups duplicate numbers together (essential for the duplication pruning step) and allows for the Early Exit optimization.
  • Duplicate Pruning:
    if (i > start && candidates[i] == candidates[i - 1]) continue;
    This line ensures that at any specific depth level in our recursive tree, we do not start branches with the exact same number if we have already explored it. Since the array is sorted, duplicates are adjacent.
  • Early Exit Optimization:
    if (candidates[i] > remain) break;
    If the current candidate is strictly greater than the remaining target, it's impossible to form a valid combination. Because the array is sorted, all subsequent candidates will also be larger, so we can completely break out of the loop instead of just continue.
  • Choose, Explore, Un-choose:
    The classic backtracking template. We add the candidate to the path, recursively call the function with updated remaining target and advancing the start index (i + 1 to avoid reusing), and then remove the candidate from the path when the recursion returns to explore the next option.
Time Complexity O(2^N)

Where $N$ is the length of the candidates array. In the worst-case scenario (e.g., all 1s and a large target), the algorithm explores a binary decision tree of depth $N$. However, the sorting, duplicate pruning, and early exits significantly reduce the constant factor, making it run much faster in practice.

Space Complexity O(N)

The space complexity is dominated by the recursion stack. In the worst case, the recursive call stack depth will be equal to the length of the candidates array, $N$. The current list also uses at most $O(N)$ space. (Note: Output space for storing valid combinations is generally not counted towards auxiliary space complexity).
