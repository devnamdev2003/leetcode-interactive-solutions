Algorithm Logic & Theory

This problem relies on a Stack to track robots moving right ('R'). Since all robots move at the same speed, a collision occurs exclusively when a right-moving robot is positioned to the left of a left-moving robot.

Core Steps:

  • Sort Indices: Instead of moving the actual data and losing the original ordering, we create an array of indices `0 to n-1` and sort it based on the `positions` array to process left-to-right.
  • Stack 'R' Robots: When encountering a robot moving 'R', push its index to the stack.
  • Resolve 'L' Robots: When encountering an 'L' robot, repeatedly check the top of the stack (which holds the right-most 'R' robot so far). Resolve the collision by comparing healths, deducting points, and popping the stack when necessary.
  • Reconstruct: Loop through the original `healths` array and pick non-zero values to retain the initial indexing order.
Time Complexity O(N log N)

Sorting the indices array is the dominant operation, taking O(N log N). Stack processing is O(N) because each robot is pushed and popped at most once during the resolution phase.

Space Complexity O(N)

The algorithm requires O(N) auxiliary space to store the sorted `indices` array, the `Stack` holding the 'R' robots, and the resulting list of survivals.
