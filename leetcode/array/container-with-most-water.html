Algorithm Logic & Theory

The Two Pointers approach provides an elegant and highly optimized solution to finding the maximum water container without checking every possible combination.

Core Concept: Proof by Contradiction

  • Start Wide: We start with the widest possible container by placing pointers at the extreme left and right ends. The area is determined by `min(height[left], height[right]) * width`.
  • The Bottleneck: The height of the container is strictly limited by the shorter of the two lines. Moving the pointer that points to the taller line inwards cannot possibly increase the area, because the height is still restricted by the shorter line, and the width is decreasing.
  • The Action: Therefore, the only logical move to potentially find a larger area is to move the pointer that points to the shorter line. By sacrificing width, we hope to find a much taller line that compensates for the width loss.
  • Convergence: We repeat this process, updating our `maxArea` variable whenever we find a larger container, until the two pointers meet.
Time Complexity O(N)

Where N is the length of the heights array. The two pointers traverse the array exactly once. At each step, either the left pointer increments or the right pointer decrements until they meet.

Space Complexity O(1)

The algorithm requires constant extra space. Only a few integer variables (`left`, `right`, `maxArea`, `currentArea`) are maintained regardless of the size of the input array.
