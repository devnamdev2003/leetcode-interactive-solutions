Algorithm Logic & Theory

This solution uses a HashMap (Frequency Counting) approach to find the Majority Element. By definition, a majority element is an element that appears more than ⌊n / 2⌋ times in an array of size n.

Core Steps:

  • Step 1: Map Initialization
    We initialize an empty Hash Map (dictionary) to store each unique element of the array as a Key and its frequency of occurrence as the Value.
  • Step 2: Frequency Counting (First Pass)
    We iterate through the array. For each element, we check if it already exists in the Hash Map. If it doesn't, we add it with a frequency of 1. If it does exist, we retrieve its current frequency, increment it by 1, and update the Map.
  • Step 3: Finding the Majority (Second Pass)
    We iterate through the array (or the map keys) one more time. For each element, we check its frequency in the map. If the frequency is strictly greater than n / 2, we have found our majority element and return it immediately.
Time Complexity O(N)

Where N is the length of the array. We perform two separate passes over the array. Inserting into and retrieving from a HashMap takes O(1) time on average. Thus, O(N) + O(N) simplifies to O(N) linear time.

Space Complexity O(N)

In the worst-case scenario (e.g., all elements are unique), the HashMap will store a separate key-value pair for every single element in the array, requiring O(N) extra auxiliary memory.
