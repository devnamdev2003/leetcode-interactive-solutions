Algorithm Logic & Theory

This solution uses an ingenious In-Place Cyclic Marking approach. The problem asks us to find missing numbers in an array of size $N$ where elements are constraint to the range $[1, N]$, with the extra challenge of using $O(1)$ extra space and $O(N)$ runtime.

Core Concept: The Array as its Own Hash Map

  • Pass 1: Negation to Mark Presence
    As we iterate through the array, we treat every absolute value we see as an index. For a value $X$, we navigate to index $X - 1$ and negate the number at that index. By turning the number negative, we mathematically mark that "we have seen the number $X$." We use the absolute value `Math.abs()` to jump around because the number we are currently reading might have already been flipped to negative by a previous operation.
  • Pass 2: Finding the Unmarked
    After checking all elements, we do a second linear pass over the array. If the number at index $i$ is still positive, it means no element ever pointed to this index during the first pass. Therefore, the number $i + 1$ never appeared in the array!
Time Complexity O(N)

We iterate through the entire input array exactly twice. The first pass to mark the elements, and the second pass to collect the positive numbers. Inside the loop, the negation and array lookup take $O(1)$ constant time. Thus, the total time is strictly bounded by $O(N)$.

Space Complexity O(1) Auxiliary

Excluding the space required to store the returned list of missing numbers (which does not count towards auxiliary space per standard complexity analysis), we use exactly zero extra data structures. We mutate the original array in-place, yielding an elegant $O(1)$ space requirement.
