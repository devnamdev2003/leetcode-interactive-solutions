Algorithm Logic & Theory

This solution utilizes the highly efficient Boyer-Moore Voting Algorithm. It is designed to find the majority element (an element that appears more than ⌊n / 2⌋ times) in an array with minimal space and time overhead.

Core Concept: Canceling Out

Think of the algorithm like a battle between different elements. The majority element has an army strictly greater than the combined armies of all other elements. If a soldier from one army fights a soldier from a different army, they both cancel each other out. Ultimately, the majority element's army will be the only one with soldiers remaining.

Execution Steps:

  • Maintain State: The algorithm keeps track of a candidate (res) and a count (majority).
  • Select Candidate: If the count drops to 0, the current element becomes the new candidate.
  • Vote Processing: As we iterate, if the current element matches the candidate, the count goes up by 1 (+1 vote). If it is different, the count goes down by 1 (-1 vote, effectively canceling out a previous vote).
Time Complexity O(N)

Where $N$ is the number of elements in the array. We only need to traverse the array a single time. During traversal, we perform constant time $O(1)$ operations (variable updates and simple conditionals).

Space Complexity O(1)

The algorithm only allocates two primitive integer variables (res and majority). The memory footprint stays strictly constant regardless of how large the input array grows, making it highly optimal.
