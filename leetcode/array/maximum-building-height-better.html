Algorithm Logic & Theory

This specific variation visualizes an $O(m^2)$ Restriction Propagation approach to solve the Maximum Building Height problem. While an optimal $O(m \log m)$ solution exists using two passes, this $O(m^2)$ technique excellently demonstrates the core geometric constraint logic.

Core Concepts:

  • The Core Rule: A building's height cannot exceed its neighbor's height plus the distance between them. E.g., if Building 2 is restricted to height 1, Building 5's height cannot exceed $1 + |5 - 2| = 4$.
  • Propagation ($O(m^2)$): To ensure all restrictions are globally valid, we cross-reference every restriction against every other restriction. For any pair r1 and r2, we update r1.maxHeight = min(r1.maxHeight, r2.maxHeight + distance).
  • Peak Calculation: After all restrictions strictly conform to each other, the maximum possible height between any two adjacent sorted restrictions r1 and r2 occurs at the intersection of two 45-degree lines growing from them. The peak formula is:
    peak = (r1.height + r2.height + distance) / 2
Time Complexity O(m²)

Where $m$ is the number of restrictions. The nested loop compares every restriction to every other. Note: Optimal approach uses a Left-to-Right then Right-to-Left pass for $O(m \log m)$.

Space Complexity O(m)

Where $m$ is the number of restrictions. We construct a list to store and sort the given restrictions, plus the boundaries (Building 1 and Building N).
