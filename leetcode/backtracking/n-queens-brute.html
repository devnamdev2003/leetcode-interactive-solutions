Algorithm Logic & Theory

This solution uses a Backtracking approach to solve the classic N-Queens problem. The objective is to place $N$ queens on an $N \times N$ chessboard so that no two queens threaten each other. This means no two queens can share the same row, column, or diagonal.

Core Steps:

  • Step 1: Column-by-Column Placement
    The algorithm uses a recursive function fun() that tries to place exactly one queen per column. The variable cl tracks the current column. If cl reaches $N$, a valid board configuration has been found.
  • Step 2: Check for Safety (Pruning)
    For a given column, it iterates through every row i. Before placing a queen, it calls isSafe(). Because we are filling column by column from left to right, we only need to check for conflicts to the left of the current cell: the upper-left diagonal, the left row, and the lower-left diagonal.
  • Step 3: Place, Recurse, and Backtrack
    If the cell is safe, it tentatively places a queen (m[i][cl] = 1) and recursively moves to the next column (cl + 1). If that path fails to yield a solution (or after exploring it fully), it backtracks by removing the queen (m[i][cl] = 0) and tries the next row in the current column.
Time Complexity O(N!)

Strictly speaking, the first queen has $N$ row choices, the second has $N-1$ valid choices (approx), the third $N-2$, etc. Thus, the upper bound of the recursion tree is $O(N!)$. Pruning drastically reduces actual runtime, but the worst-case bound remains factorial.

Space Complexity O(N²)

The 2D board matrix m[N][N] takes $O(N^2)$ space. Additionally, the recursion stack can go up to $N$ frames deep, taking $O(N)$ space. Storing the final answers takes $O(S \cdot N^2)$ where $S$ is the number of solutions.
