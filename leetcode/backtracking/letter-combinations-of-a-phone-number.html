Algorithm Logic & Theory

This algorithm uses Backtracking to systematically build combinations of letters mapped to a provided string of digits. Thinking of this as a recursive tree is the best way to understand the branching logic.

Core Concept:

  • Recursive Exploration (Tree Branching): Each function call represents a node in the tree. For the current digit at index c, we loop through its mapped letters. Every time we append a letter and recursively call fun(), we traverse down a branch to the next level of the tree.
  • The Base Case (Leaf Nodes): When the index c matches the input length, we reach a leaf node. We have successfully formed a valid combination! We add the string to ans and return upward.
  • The Backtrack Step (Moving back up the tree): After returning from a branch, we must undo our choice before exploring the next branch. By removing the last character (v.deleteCharAt(...)), we climb back up to the parent node's state, ready to loop to the next available character sibling.
Time Complexity O(4N × N)

Where N is the length of the digits string. In the worst case, a digit maps to 4 letters (like '7' or '9'). Thus, the tree has at most 4N leaf nodes. Building the string and adding it to the list takes O(N) time at each leaf.

Space Complexity O(N)

The auxiliary space is proportional to the maximum depth of the recursive tree. The recursion stack and the StringBuilder both go exactly N levels deep. (Excludes space required for the output array).
