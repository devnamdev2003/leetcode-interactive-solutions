Algorithm Logic & Theory

This solution uses a classic Backtracking approach (Depth-First Search) to find all possible paths from the top-left (0,0) to the bottom-right (N-1, N-1) of a matrix.

Core Steps:

  • Step 1: Boundary & Validity Checks
    At each cell, the algorithm checks if it is out of bounds, if the cell is blocked (maze[i][j] == 0), or if it has already been visited in the current path. If any of these are true, it trims the branch (returns).
  • Step 2: Base Case (Destination Reached)
    If the rat reaches (N-1, N-1), it has found a valid path. The current directional string s is added to the answers list, and it returns to explore other branches.
  • Step 3: Mark & Explore (DLRU)
    The cell is marked as visited. Then, it recursively calls itself in Lexicographical order: Down, Left, Right, Up. Appending the respective character to the path string.
  • Step 4: Backtrack
    After exploring all 4 directions from a cell, it removes the character from the string and unmarks the cell (visited[i][j] = 0). This is crucial; it frees up the cell so it can be used in an entirely different path originating from another branch.
Time Complexity O(4^(N²))

At every cell, the rat has up to 4 choices (D, L, R, U). In the absolute worst-case scenario (an empty maze where it spirals everywhere), it can explore an exponential number of paths bounded by the total number of cells $N \times N$. While practically faster due to pruning and obstacles, $4^{N^2}$ is the theoretical loose upper bound. Path length is at most $N^2$, taking $O(N^2)$ to copy strings, making it $O(4^{N^2} \times N^2)$.

Space Complexity O(N²)

The auxiliary space is dominated by the recursion stack and the visited matrix. The recursion depth can go up to $N \times N$ if the path snakes through every single cell. The visited array is also size $N \times N$. Therefore, auxiliary space is strictly bounded to $O(N^2)$, excluding the space required to hold the final answers.
