Algorithm Logic & Theory

This solution uses the Backtracking paradigm to solve the Sudoku problem. It explores the search space recursively by attempting valid candidate numbers and "backing out" when it hits a dead end.

Core Steps:

  • Find Empty Cell: The algorithm scans the 9x9 board row by row until it finds a cell with a '.' character.
  • Try Candidates (1-9): For the empty cell, it iteratively tries inserting numbers from '1' to '9'.
  • Validation isValid(): Before placing a number, it strictly checks if the number already exists in the current row, column, or 3x3 subgrid.
  • Recursive Branching: If valid, the number is placed, and fun(board) is called again to solve the rest of the board. This forms a deep recursive tree path.
  • Backtracking: If the recursive call returns false (meaning the board became unsolvable down that path), the algorithm resets the cell back to '.' and tries the next candidate number.
Time Complexity O(9N)

Where N is the number of empty cells. For every empty cell, we make up to 9 recursive branches in the worst-case scenario. Validations prune the tree significantly, making the average runtime much faster, but the absolute upper bound theoretical complexity remains exponential.

Space Complexity O(N)

The space complexity is determined by the maximum depth of the recursive call stack tree. Since we only recurse when placing a number in an empty cell, the call stack will go at most N levels deep. The 9x9 board is passed by reference and modified in place, taking $O(1)$ auxiliary space.
