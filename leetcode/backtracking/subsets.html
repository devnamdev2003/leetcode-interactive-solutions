Algorithm Logic & Theory

This solution uses the classic Backtracking (Pick / Not-Pick) technique to generate all possible subsets (the Power Set) of an array.

Core Concept:

At every element in the input array, we have exactly two choices: we can either include the element in our current subset, or we can exclude it. By recursively exploring both choices for every single element, we form a binary recursion tree that explores all possible combinations.

Execution Flow:

  • Base Case (i == nums.length): When our pointer i reaches the end of the array, our current path s1 represents one complete subset. We add a copy of it to our final answer list.
  • The "Include" Branch: We add nums[i] to s1 and recursively call fun2 for the next index i + 1.
  • The "Backtrack" Step: We remove the element we just added. This undoes the state change so we can explore the alternate path with a clean slate.
  • The "Exclude" Branch: With the element removed, we recursively call fun2 for the next index i + 1 without including nums[i].
Time Complexity O(N · 2^N)

Where $N$ is the length of the array. There are $2^N$ possible subsets because every element has 2 choices (include/exclude). For every valid subset at the base case, creating a deep copy to store it takes $O(N)$ time.

Space Complexity O(N)

The auxiliary space complexity is $O(N)$ due to the depth of the recursive call stack and the temporary list s1 used to build subsets. This excludes the $O(N \cdot 2^N)$ space required to hold the output array itself.
