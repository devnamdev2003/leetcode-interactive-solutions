Algorithm Logic & Theory

This algorithm uses a Backtracking approach to generate all possible permutations of an array. Backtracking is a systemic way of exploring all potential solutions by building a solution step by step and "backing up" when a path is fully explored or hits a dead end.

Core Steps:

  • Step 1: Track State
    We maintain an array mark to remember which elements from nums have already been included in our current path v.
  • Step 2: Base Case (The Goal)
    If the current path v has the same length as the input nums, we have formed a complete permutation! We add a copy of v to our final answer list ans and return.
  • Step 3: Explore Choices (Recursive Step)
    We loop through every element j in nums. If it is not marked, we:
    1. Choose: Add nums[j] to path v and mark it as used (mark[j] = true).
    2. Explore: Recursively call the function to pick the next elements.
    3. Un-choose (Backtrack): Once the recursion returns, we undo our choice! Remove nums[j] from v and unmark it (mark[j] = false). This allows nums[j] to be picked in a different position in another permutation branch.
Time Complexity O(N × N!)

Where $N$ is the length of the array. There are exactly $N!$ (N factorial) permutations possible. For each permutation, copying the current list v into the final answer list takes $O(N)$ time.

Space Complexity O(N)

The auxiliary space is $O(N)$ due to the recursion stack depth reaching $N$, the mark boolean array of size $N$, and the temporary path list v. (Note: The final output array ans takes $O(N \times N!)$ space, which is typically excluded from auxiliary space calculations).
