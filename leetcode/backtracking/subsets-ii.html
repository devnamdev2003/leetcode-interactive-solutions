Algorithm Logic & Theory

This solution uses a Backtracking approach to generate all possible unique subsets (the power set) of an array that may contain duplicates. To handle duplicates efficiently, the array is first sorted.

Core Steps:

  • Step 1: Sort the Array
    Sorting ensures that duplicate elements are adjacent to each other. This is a critical prerequisite because it allows us to easily detect and skip duplicates in the recursive loop.
  • Step 2: Recursive Backtracking (Explore paths)
    At each function call, the current subset v is immediately added to our answer list ans. Then, we loop through the remaining elements starting from index i. We add an element to our subset, recursively call the function to explore further, and then backtrack (remove the element) to explore alternative branches.
  • Step 3: Skip Duplicates
    Inside the for loop, we check if (j > i && nums[j] == nums[j - 1]). If true, we continue. Why? If an element is the same as the one right before it, and we are not at the start of our current recursion level (j > i), exploring it would create the exact same subset tree we just explored for the previous identical element.
Time Complexity O(2N × N)

Where $N$ is the number of elements. In the worst case (all unique elements), there are $2^N$ possible subsets. For each valid subset, we add a copy of it to the result list, which takes $O(N)$ time. Sorting takes $O(N \log N)$ but is dominated by the generation phase.

Space Complexity O(N) Auxiliary

The auxiliary space is $O(N)$ due to the maximum depth of the recursion stack and the memory required to maintain the current subset list v. The space required to store the final output ans is $O(2^N \times N)$.
