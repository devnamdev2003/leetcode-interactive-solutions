Algorithm Logic & Theory

This algorithm rebuilds a unique Binary Tree given its Preorder and Inorder traversals. It beautifully combines array parsing with recursive divide-and-conquer logic.

Core Concepts:

  • Preorder Traversal (Root, Left, Right):
    The most critical property of Preorder is that the first element is always the root of the current subtree. By maintaining a global pointer k, we can sequentially pick roots as we build the tree from top to bottom.
  • Inorder Traversal (Left, Root, Right):
    Once we know the root (from Preorder), finding it in the Inorder array tells us exactly how many elements are in the left subtree versus the right subtree. Everything to the left of the root index belongs to root.left, and everything to the right belongs to root.right.
  • HashMap Optimization:
    Instead of doing a linear search $O(N)$ for the root in the inorder array every recursive step, we map value -> index upfront. This reduces the lookup time to $O(1)$.
Time Complexity O(N)

Building the initial HashMap takes $O(N)$. The recursive function visits each node exactly once to construct the tree, and the HashMap lookup is $O(1)$. Total Time Complexity is strictly linear, $O(N)$.

Space Complexity O(N)

The HashMap requires $O(N)$ auxiliary space to store the indices. Additionally, the recursive call stack takes $O(H)$ space, where $H$ is the tree height. In the worst case (a skewed tree), $H = N$. Total space is $O(N)$.
