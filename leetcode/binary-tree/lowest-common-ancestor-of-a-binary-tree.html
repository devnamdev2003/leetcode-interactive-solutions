Algorithm Logic & Theory

This solution utilizes Depth First Search (DFS) to recursively traverse the binary tree from the bottom up. By leveraging the recursion stack, it elegantly determines the Lowest Common Ancestor (LCA) in a single pass without needing parent pointers.

Core Logic:

  • Base Case Verification:
    If the current node is null, we've reached a leaf's child; we return null. If the current node matches either target p or target q, we immediately return the current node. This propagates the found node upwards.
  • Recursive Traversal:
    We recursively call the function on both the left and right children. This searches both subtrees for p and q.
  • Result Evaluation (The "Aha" Moment):
    Once the left and right recursive calls return, we check their values:
    - If both left and right are non-null, it means one target was found in the left subtree, and the other in the right subtree. This makes the current node the LCA, so we return it.
    - If only one child returns a non-null value, it means both nodes are located in that single subtree (or we only found one target so far). We bubble up that non-null value to the parent.
    - If both are null, neither target exists in this subtree.
Time Complexity O(N)

In the worst-case scenario, the algorithm visits every node in the binary tree exactly once during the Depth First Search traversal. Therefore, the time complexity scales linearly with the number of nodes $N$.

Space Complexity O(H) / O(N)

The auxiliary space is determined by the maximum depth of the recursion stack, which equals the height of the tree $H$. In a balanced tree, $H = \log N$. However, in a skewed (degenerate) tree, $H = N$, making the worst-case space complexity $O(N)$.
