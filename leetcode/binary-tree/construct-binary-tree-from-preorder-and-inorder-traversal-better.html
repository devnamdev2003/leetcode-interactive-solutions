Algorithm Logic & Theory

This algorithm uses a Divide & Conquer / Recursive approach to construct a Binary Tree. It leverages the unique properties of Preorder (Root, Left, Right) and Inorder (Left, Root, Right) traversals.

Core Steps:

  • Step 1: Identify the Root
    The first element of the preorder traversal is always the root of the current subtree. We pick this element and increment our global preIndex.
  • Step 2: Find Left and Right Subtrees
    We search for this root value inside the inorder array. The elements to the left of this root in the inorder array form the left subtree, and elements to the right form the right subtree.
  • Step 3: Recursive Construction
    We recursively call our helper function for the left portion (from l to rootIndex - 1) and attach it to root.left. Then we do the same for the right portion (from rootIndex + 1 to r).
Time Complexity O(N²) worst-case

In the provided solution, for each node, we perform a linear search O(N) to find the root in the inorder array. Across N nodes, this is $O(N^2)$.

Note: This can be optimized to O(N) by preprocessing the inorder array into a HashMap for O(1) lookups!

Space Complexity O(N)

The auxiliary space is $O(N)$ representing the maximum depth of the recursion stack. This worst-case scenario happens if the tree is completely skewed (like a linked list). The tree itself also requires $O(N)$ space to store the constructed nodes.
