Algorithm Logic & Theory

This solution cleverly uses the Sliding Window technique to solve the "Binary Subarrays With Sum" problem in $O(N)$ time.

The "At Most" Trick

Finding subarrays with an exact sum can be tricky, especially with sliding windows, because adding a '0' doesn't change the sum, meaning you might have multiple valid window bounds for the same sum.

To bypass this, we use a math trick:
Count(Exact Goal) = Count(At Most Goal) - Count(At Most Goal - 1)

Think of it like finding people exactly 5 feet tall by taking all people 5 feet and under, and subtracting everyone 4'11" and under.

How `subarraysWithSumAtMost` works:

  • Maintain a sliding window defined by pointers l (left) and r (right).
  • Expand the window by moving r to the right and adding nums[r] to the sum.
  • If the sum exceeds our target k, the window is invalid. We shrink it from the left by subtracting nums[l] and moving l right until the sum is $\le k$.
  • The Magic Step: Once the window `[l, r]` is valid, it means all sub-windows ending at r are also valid. How many are there? Exactly r - l + 1. We add this to our count.
Time Complexity O(N)

Although we call the helper function twice, each call runs in $O(N)$ time. The inner while loop only shrinks the window. Both l and r traverse the array at most once per pass. Thus, $O(2N) \rightarrow O(N)$.

Space Complexity O(1)

The algorithm only uses a few integer variables (l, r, sum, count) regardless of the size of the input array. No auxiliary data structures are needed.
