Algorithm Logic & Theory

This solution uses the Sliding Window technique to find the contiguous subarray of given length k that has the maximum average value.

Core Steps:

  • Initialization (First Window):
    Instead of recalculating the sum of every possible subarray of size k from scratch, we first calculate the sum of the very first window of size k (from index 0 to k-1).
  • Sliding the Window:
    To process the next window, we don't need to loop through k elements again. We simply take the previous sum, add the new element entering the window on the right (nums[j+1]), and subtract the old element leaving the window from the left (nums[i]).
  • Tracking the Maximum:
    After updating the sum for the new window, we compare it to our current max and update max if the new sum is greater.
  • Final Calculation:
    Because the divisor (k) is constant for all subarrays, the subarray with the maximum sum naturally has the maximum average. We return max / k at the end.
Time Complexity O(N)

Where $N$ is the number of elements in the array. We calculate the sum of the first k elements in $O(k)$ time. Then, we slide the window through the rest of the array, performing $O(1)$ operations for each step. The overall time taken is $O(k) + O(N - k) = O(N)$.

Space Complexity O(1)

The algorithm only uses a few primitive variables (i, j, sum, max) to keep track of the window bounds and sums. No additional data structures are created that scale with the input size, resulting in constant auxiliary space.
