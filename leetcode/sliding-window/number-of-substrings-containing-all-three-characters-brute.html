Algorithm Logic & Theory

This solution uses a Brute Force approach to count the number of substrings containing at least one occurrence of all three characters ('a', 'b', and 'c').

Core Logic:

  • Outer Loop (`i`): Fixes the starting point of the substring. It iterates through every character in the string.
  • Inner Loop (`j`): Expands the substring starting from `i` to `j`. It checks characters one by one.
  • State Tracking: An integer array `visi` of size 3 is used as a frequency map (or rather, a boolean existence map) to track if 'a', 'b', and 'c' have been encountered in the current substring `s[i...j]`.
  • Counting: As soon as `visi[0] + visi[1] + visi[2] == 3`, it means the current substring contains all three characters. We increment `count`.

    Crucial observation: The inner loop continues even after finding a valid substring. This is because if `s[i...j]` is valid, then `s[i...j+1]`, `s[i...j+2]`, etc., will also be valid. The code simply re-evaluates the condition and increments `count` for all larger valid substrings starting at `i`.
Optimization Note: While this $O(N^2)$ solution works, this problem is classically solved in $O(N)$ time using a Sliding Window (Two Pointers) approach by tracking the most recent indices of 'a', 'b', and 'c'.
Time Complexity O(N²)

Due to the nested loops. In the worst case, for every character at index `i`, we iterate through the remaining $N-i$ characters, leading to $\approx N^2/2$ operations.

Space Complexity O(1)

The auxiliary space is constant $O(1)$. We create a new array `visi` of fixed size 3 inside the loop. No additional memory scaling with the input string length $N$ is required.
