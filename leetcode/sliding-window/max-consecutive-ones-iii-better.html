Algorithm Logic & Theory

This solution utilizes the highly efficient Sliding Window pattern, specifically the dynamically resizable variant, to solve the problem in a single pass.

Core Concept:

Instead of flipping 0s physically, we reframe the problem: "Find the longest contiguous subarray that contains at most k zeros."

  • Expand the Window (Right Pointer):
    We iterate a right pointer (r) through the array. Every time we encounter a 0, we increment our count (representing a flip). As long as count <= k, our window [l, r] is valid.
  • Shrink the Window (Left Pointer):
    If our window becomes invalid (count > k), we must shrink it from the left. We move the left pointer (l) forward. If the element leaving the window (nums[l]) was a 0, we successfully "un-flip" it by decrementing count. We repeat this via a while loop until the window is valid again.
  • Track Maximum:
    At the end of every valid window expansion/adjustment step, we calculate the current window length (r - l + 1) and update our global len maximum.
Time Complexity O(N)

Where N is the number of elements in the array. Both the left pointer (l) and right pointer (r) only move forward. Each element is visited at most twice (once by r, once by l), making it linear time.

Space Complexity O(1)

We only use a few integer variables (l, r, len, count) to maintain the state of the window. No additional data structures are created that scale with input size.
