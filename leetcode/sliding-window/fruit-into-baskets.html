Algorithm Logic & Theory

This solution utilizes an optimized Sliding Window technique to solve the "Fruit Into Baskets" problem. The goal is to find the longest contiguous subarray containing at most two distinct elements.

Core Concept: Bounded Window Optimization

A traditional sliding window uses a while loop to shrink the left pointer until the window becomes valid again. However, this specific implementation uses an if statement.

if (count > 2) { shrinkLeft(); l++; }

  • Why an `if`? We only care about the maximum window size. If we expand the right pointer (`r++`), the window length increases by 1.
  • If this expansion introduces a 3rd distinct fruit (making it invalid), the `if` block executes, shifting the left pointer right by exactly one position (`l++`).
  • The result: The window shifts to the right, but its length remains unchanged. It is "bounded" by the maximum length found so far. It will never shrink below its max size, but it will seamlessly grow when it encounters a valid stretch again.
Time Complexity O(N)

Where N is the length of the fruits array. Both pointers l and r move monotonically from left to right. Each pointer traverses the array at most once. The operations inside the loop (array indexing, comparisons) take constant time O(1).

Space Complexity O(N)

The code allocates an integer array frequency of size equal to the length of the input array N + 1. While a HashMap could strictly be O(K) where K=2, the chosen array-based map inherently consumes O(N) auxiliary space based on the problem constraints.
