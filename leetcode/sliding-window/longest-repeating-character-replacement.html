Algorithm Logic & Theory

This solution employs an optimal Sliding Window technique using two pointers (L and R) and a frequency Map (array) to find the longest valid substring in a single pass.

Core Concept: The "Valid Window" Equation

For any window of string s from index L to R, the minimum number of character replacements needed to make all characters in the window identical is:

Replacements = (Window Size) - (Count of Most Frequent Character)

If Replacements <= k, the window is valid. We can extend it by moving R to the right.

The "Shift" Optimization

Notice the if condition instead of a while loop to shrink the window:

if (r - l + 1 - maxf > k) {
    hash[s.charAt(l) - 'A']--;
    l++;
}

When the window becomes invalid, we increment l just once. Because r also increments in the loop, the window size remains strictly constant. We don't shrink the window down to a valid size; we just shift a window of the maximum valid size seen so far to the right.

The variable maxf tracks the historical maximum frequency seen in any valid window. We only need to grow the window if we find a frequency that exceeds this historical max. This clever trick avoids the need to rescan the hash map every time we shrink the window, keeping the time complexity strictly linear.

Time Complexity O(N)

Where N is the length of string s. The right pointer R iterates through the string exactly once. The left pointer L also moves at most N times. Accessing and updating the frequency array takes $O(1)$ time. Thus, strictly linear time.

Space Complexity O(1)

The auxiliary space is used by the hash array to store character frequencies. Since the problem limits characters to uppercase English letters, the array size is always strictly 26. This is constant space, regardless of the input string size N.
