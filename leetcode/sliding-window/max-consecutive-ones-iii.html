Algorithm Logic & Theory

This solution utilizes a highly optimized Sliding Window technique. The goal is to find the longest contiguous subarray containing only 1s, with the caveat that we are allowed to "flip" at most k zeros to 1s.

The "Non-Shrinkable" Window Trick

Standard sliding window algorithms usually use a while loop to shrink the window from the left until it becomes valid again. However, this specific implementation uses a clever trick with a simple if statement:

if (count > k) {
    if (nums[left] == 0) count--;
    left++;
}
  • Because we are only interested in finding the maximum length, there is no need to shrink the window once it has reached a certain size.
  • When the window becomes invalid (count > k), instead of shrinking it, we shift the entire window to the right by incrementing both i (in the for loop) and left (in the if block).
  • This means the window acts like a watermark: it grows when a valid larger window is found, but when it encounters too many zeros, it maintains its maximum size and rigidly slides forward hoping to encapsulate a new valid sequence.
Time Complexity O(N)

Where N is the length of the array. The right pointer (i) traverses the array exactly once. The left pointer (left) also moves forward at most N times. Therefore, the total number of operations is proportional to N.

Space Complexity O(1)

The algorithm only uses a few primitive integer variables (len, left, count, i) to keep track of the window state and the maximum length found so far. No extra auxiliary data structures are created.
