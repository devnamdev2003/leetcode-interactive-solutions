Algorithm Logic & Theory

This solution utilizes a Hash Map (Frequency Counting) approach. It is designed to efficiently identify one missing number and one repeated number within an $N \times N$ matrix that supposedly contains all integers from $1$ to $N^2$.

Core Concept: Frequency Map

A typical $N \times N$ grid contains elements from $1$ to $N^2$ exactly once. If one element is repeated, another must be omitted. By keeping track of how many times each number appears using a hash map (or frequency array), we can easily deduce both values.

Execution Steps:

  • Phase 1 - Matrix Traversal: We iterate over every row i and column j in the matrix. For every cell, we push its value into the Hash Map, incrementing its frequency count by 1.
  • Phase 2 - Range Check: Once the map is fully populated, we iterate through the ideal sequence of numbers from 1 to N * N.
  • Evaluation: For each number in the sequence, we check the map. If a number's count is > 1, it's our Repeated value. If a number is absent (or count 0), it is our Missing value.
Time Complexity O(N²)

Where $N$ is the side length of the grid. Phase 1 visits $N \times N$ elements. Phase 2 loops from 1 to $N^2$. Both phases perform constant $O(1)$ time hash map lookups. Overall runtime scales linearly with the total number of elements.

Space Complexity O(N²)

The algorithm relies on a Hash Map to store the frequencies. In the worst case, it stores nearly all unique values up to $N^2$. Therefore, the space complexity grows proportionally to the total amount of elements in the grid.
