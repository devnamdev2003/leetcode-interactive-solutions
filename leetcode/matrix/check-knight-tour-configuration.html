Algorithm Logic & Theory

This solution validates if a given grid represents a valid Knight's Tour. In a valid tour, a knight starts at the top-left corner (0) and visits every cell exactly once, following standard "L-shaped" chess moves. The grid contains integers representing the order of visitation.

Core Steps:

  • Step 1: Start Condition
    The knight must start at cell (0,0) and its assigned step number must be 0. If not, the function immediately returns false.
  • Step 2: Track Target Steps
    We initialize a variable count = 1 (the next step to find) and the knight's starting position i = 0, j = 0. A loop continues until we have found steps up to N*N - 1.
  • Step 3: Move Verification
    For the current position, the algorithm checks all 8 possible knight jump vectors. If a valid jump lands inside the grid bounds and the cell value matches the current count, we update the knight's position to this cell, increment count, and break out of the direction loop.
  • Step 4: Path Break Detection
    If we check all 8 directions and fail to find the required next step (i.e., temp == count meaning count was not incremented), the tour is broken, and we return false.
Time Complexity O(N²)

The grid has $N^2$ cells. The outer while loop runs exactly $N^2 - 1$ times for a valid tour. Inside, the for loop strictly iterates a maximum of 8 times (constant time). Therefore, the overall upper bound scales directly with the number of cells in the grid, yielding $O(N^2)$.

Space Complexity O(1)

Excluding the input grid itself, the algorithm only uses a constant amount of auxiliary memory: simple scalar variables (i, j, count, temp, r, c) and an 8x2 static array for the move vectors. No additional dynamic data structures are created.
