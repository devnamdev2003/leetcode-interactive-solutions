Algorithm Logic & Theory

This solution utilizes a Frequency Array approach. It is designed to efficiently identify one missing number and one repeated number within an $N \times N$ matrix by using a fixed-size integer array rather than the overhead of a Hash Map.

Core Concept: Index Mapping

Because the grid contains values from $1$ to $N^2$, we can allocate an array `freq` of size $N^2 + 1$. This allows us to use the numbers themselves as direct indices into the array. If we read the number `x`, we simply increment `freq[x]`.

Execution Steps:

  • Phase 1 - Direct Indexing: We loop through every row and every number in the matrix. For every number `num`, we increment `freq[num]`. This counts how many times each number occurs.
  • Phase 2 - Validation Check: Once the frequency array is populated, we loop through the valid bounds from `1` to `N^2`.
  • Evaluation: For each index `num`, we check its value. If `freq[num] == 2`, it's our Repeated value. If `freq[num] == 0`, it is our Missing value.
Time Complexity O(N²)

Where $N$ is the side length of the grid. Phase 1 iterates $N \times N$ elements. Phase 2 loops from 1 to $N^2$. Array lookups and updates are strict $O(1)$ constant time operations. Overall runtime scales linearly with the total number of elements.

Space Complexity O(N²)

The algorithm relies on a flat array of size $N^2 + 1$. Although it has the same asymptotic space complexity as a Hash Map, allocating a contiguous block of primitives is much more memory-efficient and cache-friendly than creating object nodes.
