Algorithm Logic & Theory

This algorithm solves the "Integer Break" or "Max Product of Cut Rope" problem using a purely Recursive Top-Down Approach. The core idea is that to find the maximum product for a rope of length N, we must test cutting it at every possible integer length i (from 1 to N-1) and recursively finding the max product of the remaining piece.

Core Steps:

  • Recursive Choice:
    At any point, if we make a cut of length i, the remaining piece has length n - i. We have two choices for this remaining piece:
    1. Don't cut it anymore: The product is i * (n - i).
    2. Cut it further: The product is i * maxProduct(n - i).
  • Overlapping Subproblems:
    Because the function `maxProduct(n-i)` is called repeatedly for the same values (for example, `maxProduct(2)` will be called multiple times in a larger tree), the algorithm forms an overlapping subproblem tree. (Note: In competitive programming, this would typically be optimized to $O(N^2)$ using Dynamic Programming Memoization or Tabulation).
Time Complexity O(2N)

Without memoization, the recursive tree explores all possible cutting combinations. The recurrence relation is roughly $T(N) = \sum_{i=1}^{N-1} T(N-i)$, which simplifies to $O(2^N)$ representing an exponential explosion of redundant calls.

Space Complexity O(N)

The space complexity is defined by the maximum depth of the Recursion Call Stack. The deepest recursive path goes down to $N=1$, making the stack depth strictly bounded by $O(N)$.
