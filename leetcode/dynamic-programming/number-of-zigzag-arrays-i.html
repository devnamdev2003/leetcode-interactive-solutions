Algorithm Logic & Theory

The ZigZag Arrays problem asks us to find the number of sequences of length $N$ where elements are within the range $[L, R]$, and they follow a strict zigzag pattern. Specifically, $A_0 < A_1 > A_2 < A_3 \dots$ or $A_0 > A_1 < A_2 > A_3 \dots$

Dynamic Programming & Optimization:

  • State Definition
    Let dp[x] be the number of valid sequences of the current length that end with the value x. We iteratively compute this for length $1$ up to length $N$.
  • Naive Transition ($O(N \cdot K^2)$)
    If we are at an odd index (requiring an increase, so $A_{i-1} < A_i = x$), the number of ways to form this sequence is the sum of all valid sequences of length $i-1$ ending in $y$, where $y < x$. Naively summing dp[y] for all $y \in [L, x-1]$ inside the loop takes $O(K)$ time, leading to cubic overall complexity.
  • Prefix / Suffix Sum Optimization ($O(N \cdot K)$)
    Instead of an inner loop, we can maintain a running total.
    - For Increasing (Odd indices): We iterate $x$ from $L$ to $R$. The sum of dp[y] for $y < x$ is exactly the prefix sum of the previous DP row up to $x-1$. We maintain this in a variable pre.
    - For Decreasing (Even indices): We iterate $x$ from $R$ down to $L$. The sum of dp[y] for $y > x$ is the suffix sum, maintained in a variable suff.
  • Symmetry
    The algorithm calculates the answer assuming the pattern starts with an "increase". Because the bounds $[L, R]$ are symmetric regardless of starting direction, the number of arrays starting with a "decrease" is exactly the same. Thus, we simply multiply the final count by 2.
Time Complexity O(N × (R - L))

Where $N$ is the length of the array, and $K = (R - L + 1)$ is the range of valid numbers. The outer loop runs $N$ times. Thanks to the Prefix/Suffix sum optimization, the inner loop processes each of the $K$ elements in $O(1)$ time.

Space Complexity O(R)

The space complexity is determined by the two arrays dp and next_dp, each allocated to size $R + 1$. Note: Space could be further optimized to $O(R - L)$ by shifting array indices, but $O(R)$ keeps the index logic simple.
