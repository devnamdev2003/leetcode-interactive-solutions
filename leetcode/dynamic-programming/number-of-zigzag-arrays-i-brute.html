Algorithm Logic & Theory

This solution utilizes a Backtracking approach to explore all possible combinations of arrays of length n, filtering them dynamically to enforce the "ZigZag" rule.

Core Constraints (The ZigZag Rules):

  • No Adjacent Duplicates:
    If the list has elements, the candidate element i cannot be equal to the immediate previous element. Handled by: v.get(v.size() - 1) == i
  • No Strict Monotonic Subsequences of Length 3:
    If the list has at least 2 elements, we look at the last two (a and b) and the candidate (c = i). They cannot be strictly increasing (a < b < c) or strictly decreasing (a > b > c). The sequence must change direction.
  • Recursive State Space Tree:
    We build the array element by element. When a candidate i satisfies all rules, it is temporarily added to the list (v.add(i)), and we recurse. After the branch finishes, we backtrack by removing it (v.remove(...)) to explore the next candidate.
Time Complexity O((R-L+1)^N)

Where $N$ is the length of the array, and $R-L+1$ is the number of possible values for each element. In the worst-case scenario (without pruning), the recursion branches out up to $R-L+1$ times at each of the $N$ steps, resulting in exponential time complexity.

Space Complexity O(N)

The space complexity is determined by the maximum depth of the recursion stack, which equals $N$ (the target length of the array). The backtracking list v also holds exactly up to $N$ elements at any given time.
