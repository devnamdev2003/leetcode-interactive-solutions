Algorithm Logic & Theory

This solution effectively solves the overlapping subproblems of climbing stairs by using a bottom-up Dynamic Programming (Space Optimized) approach. It is conceptually identical to generating the Fibonacci Sequence.

Core Steps:

  • The Core Logic:
    To reach the $i^{th}$ step, you could have come from the $(i-1)^{th}$ step (by taking a 1-step) or from the $(i-2)^{th}$ step (by taking a 2-step). Therefore, the total number of ways to reach step $i$ is exactly Ways(i-1) + Ways(i-2).
  • Base Cases:
    There is 1 way to reach step 1. There are 2 ways to reach step 2 (two 1-steps, or one 2-step). We prime our variables with these truths.
  • Space Optimization:
    A standard DP approach uses an array of size $N$ to store answers for every single step. However, to calculate the next step, we only need the previous two calculations. By using a sliding window of just two variables (prev2 and prev1), we eliminate the need for an array, drastically dropping memory usage!
Time Complexity O(N)

Where $N$ is the number of stairs. We loop from step 3 up to step $N$ exactly once, performing constant $O(1)$ additions at each iteration.

Space Complexity O(1)

We do not allocate an array proportional to $N$. Instead, we only keep track of a few integer variables (prev1, prev2, current), making the auxiliary space exactly $O(1)$.
