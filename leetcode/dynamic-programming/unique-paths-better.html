Algorithm Logic & Theory

This solution uses a Dynamic Programming (DP) approach. It visualizes the problem as building up solutions to smaller subproblems directly inside a 2D matrix.

Core Concept:

  • State Definition:
    We define dp[i][j] as the total number of unique paths to reach the cell at row $i$ and column $j$ starting from the top-left corner $(0,0)$.
  • Base Cases:
    Since the robot can only move right or down, there is only exactly 1 way to reach any cell in the topmost row (by keeping going right). Similarly, there is only 1 way to reach any cell in the leftmost column (by keeping going down). Therefore, we initialize the top row and left column to 1.
  • State Transition Equation:
    To reach a cell $(i, j)$, you must have come from either the cell directly above it $(i-1, j)$ or the cell directly to its left $(i, j-1)$. Thus, the total unique ways to reach $(i, j)$ is the sum of ways to reach its neighbors:
    dp[i][j] = dp[i-1][j] + dp[i][j-1]
Time Complexity O(M × N)

We iterate through each cell in the $M \times N$ matrix exactly once, doing a constant $O(1)$ addition for each cell.

Space Complexity O(M × N)

For creating the 2D DP array. Note: This can be optimized to $O(N)$ using a 1D array, but the standard matrix view is visualized here.
