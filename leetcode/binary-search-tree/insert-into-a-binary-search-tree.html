Algorithm Logic & Theory

This solution utilizes an Iterative Tree Traversal approach to insert a new value into a Binary Search Tree (BST). It leverages the core property of a BST: for any given node, all elements in its left subtree are smaller, and all elements in its right subtree are larger.

Core Steps:

  • Step 1: Empty Tree Check
    If the tree is completely empty (root == null), the new value simply becomes the new root node of the tree.
  • Step 2: Iterative Traversal
    We initialize a current pointer starting at the root. A while(true) loop is used to traverse downwards. At each step, we compare the target val with current.val.
  • Step 3: Branching & Insertion
    If val < current.val, we must go left. If the left child exists, we update current = current.left. If it is null, we've found our insertion point! We create the new node, attach it, and break the loop.
    Similarly, if val > current.val, we traverse right and apply the exact same logic.
Time Complexity O(H)

The time complexity is directly proportional to the height of the tree ($H$). On average (for a balanced BST), this is O(log N). However, in the worst-case scenario (a highly skewed or completely linear tree), the height becomes N, resulting in a time complexity of O(N).

Space Complexity O(1)

Because we used an iterative approach instead of recursion, we do not consume memory for the call stack. The only extra memory used is for a few pointer variables (like current), making the auxiliary space strictly O(1).
