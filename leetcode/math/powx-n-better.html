Fast Exponentiation Logic

This solution uses the Divide and Conquer pattern (specifically, Exponentiation by Squaring). It is significantly faster than standard iteration, dropping the calculation time drastically for very large powers.

Core Concept:

  • The Naive Approach
    To calculate $x^n$, we could multiply $x$ by itself $n$ times ($x \cdot x \cdot x ...$). This requires $O(n)$ operations. If $n = 1,000,000$, we do a million multiplications.
  • Exponentiation by Squaring (The Optimized Way)
    Instead of multiplying one by one, we can divide the problem in half recursively.
    Example for $2^{10}$:
       $2^{10} = (2^5) \cdot (2^5)$
       $2^5 = (2^2) \cdot (2^2) \cdot 2$ (Notice the extra multiplication by base when the power is odd).
  • Handling Negative Exponents
    A mathematical rule states that $x^{-n} = (1/x)^n$. The code intercepts a negative $n$, converts it to positive, and inverts $x$ to $1/x$, allowing the recursive function to work flawlessly exactly as if it were a positive exponent.
Time Complexity O(log n)

Because we divide the power by 2 at each recursive step, the number of multiplications needed drops logarithmically. Calculating $x^{1,000,000}$ takes roughly $20$ operations instead of $1,000,000$.

Space Complexity O(log n)

While we don't allocate any large arrays, the recursion creates a call stack in memory. The maximum depth of this stack corresponds directly to the number of divisions, which is $O(\log n)$.
