Algorithm Logic & Theory

This solution uses a highly optimized Mathematical / Combinatorics approach to find the K-th permutation sequence directly, avoiding the need to generate all permutations using backtracking.

Core Steps:

  • Block Partitioning Concept:
    If we have N digits, there are N! total permutations. If we group them by their first digit, we get N blocks, each containing exactly (N-1)! permutations.
  • Deducing the First Digit:
    By taking a 0-indexed K = K - 1, and dividing it by the block size perRowSize = (N-1)!, the result (K / perRowSize) immediately gives us the exact index of the digit that should be placed first from our available numbers list.
  • Iterative Reduction:
    Once a digit is picked, we append it to our answer and remove it from the list of available numbers. We then shrink our problem space: we update K = K % perRowSize (to find the rank within the newly selected block) and repeat the process for N-1 digits, using (N-2)! block sizes, until all digits are placed.
Time Complexity O(N²)

Precomputing factorials takes O(N). The main loop runs N times. Inside the loop, numbers.remove(index) requires shifting array elements, taking O(N) time. This results in a total Time Complexity of O(N * N) = O(N²). Given that N is at most 9, this is practically instantaneous compared to the O(N!) backtracking approach.

Space Complexity O(N)

We require an array fact of size N + 1 to store the precomputed factorials. We also maintain a List of available numbers which starts at size N. Building the string takes O(N) space. Therefore, the total extra memory scales linearly with N: O(N).
