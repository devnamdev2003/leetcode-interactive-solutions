# 🚀 LeetCode & Algorithms Vault

Welcome to the **LeetCode & Algorithms Vault**!

This repository is a curated collection of LeetCode solutions and computer science algorithms, designed to make learning and revisiting concepts easier.

Unlike traditional solution repositories that only contain source code, each problem is documented in its own `.html` file with explanations, approaches, complexity analysis, and code implementations. This makes the repository easy to browse and understand directly from a web browser.

---

## ✨ What Makes This Repository Different?

* **Well-Organized Structure** – Problems are grouped based on their primary pattern or technique, making navigation simple.
* **Multiple Approaches** – Many problems include brute-force, better, and optimal solutions to showcase the complete problem-solving journey.
* **Browser-Friendly Format** – Solutions are presented as HTML pages for a better reading experience.
* **Interactive Dashboard** – Includes an `index.html` page and `data.json` configuration to help search and access problems quickly.
* **Continuous Growth** – The repository is regularly updated with new problems, explanations, and algorithms.

## 🛠️ How to Use

### Clone the Repository

```bash
git clone https://github.com/your-username/your-repo-name.git
```

### Navigate to the Project

```bash
cd your-repo-name/leetcode
```

### Open the Dashboard

Simply open:

```text
index.html
```

in your preferred web browser to browse and search through all available solutions.

### Direct Access

You can also open any individual HTML file directly to view the explanation, approach, complexity analysis, and implementation for a specific problem.
